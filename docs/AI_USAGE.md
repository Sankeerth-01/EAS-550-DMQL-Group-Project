# Use of AI and Responsibility

## AI Software and Its Use

We took assistance from AI so that if we had any errors in our project, we could seek help to rectify them.

Our team developed the database design, coding, and the testing of our project. In this case, the primary use of AI was the errors understanding and error correcting suggestions.

## Prompt Descriptions

We used AI to understand the errors that occurred while executing our Python code for data verification and loading.

Furthermore, we also looked for some guidance from AI for solving the testing errors and understanding the result of our verification test.

## Testing and Validation

First, we tested our code with the help of AI before making any changes. After reviewing the code and SQL query, making the required changes, and testing the test again.

In addition, we conducted evaluations on the row counts in the database, the relationships between tables, checked whether all normal forms are satisfied, and the data loaded to make sure that everything is fine.

It is our duty as four people in the team to understand the code, SQL query, database design, and the outputs that we have provided.
